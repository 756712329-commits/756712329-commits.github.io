What we collect

This site is served as static files by GitHub Pages. We run no analytics scripts, no advertising cookies and no fingerprinting. Standard server access logs kept by GitHub (see github.com privacy statement) are the only technical record.

E-mail subscriptions

If you subscribe to our briefing, we store your e-mail address solely to deliver the newsletter. Every issue contains an unsubscribe line; one reply removes you permanently. Addresses are never sold, shared or cross-marketed.

Affiliate / outbound links

Links to exchanges and game stores are marked rel="sponsored". Clicking them transfers you to the third party, whose own cookie and privacy practices apply there; we receive aggregate commission reporting only, not personal profiles.
